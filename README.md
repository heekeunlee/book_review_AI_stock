# 할 수 있다! AI 주식 투자 - 북리뷰 인터랙티브 웹앱

이 프로젝트는 책 《할 수 있다! AI 주식 투자》(저자 머신러너)의 핵심 내용을 소개하고, 사용자가 실전 투자에 AI를 활용해 볼 수 있도록 돕는 인터랙티브 정적 웹앱입니다.

## 주요 기능

1.  **책 요약 정보:** 히어로 섹션과 목차별 아코디언을 통해 책의 핵심 메시지를 빠르게 파악할 수 있습니다.
2.  **WRAP 프레임워크 시각화:** 책을 관통하는 4단계 투자 프레임워크(WRAP)를 시각적으로 보여줍니다.
3.  **좋은 질문 만들기 도구:** 단순한 질문을 AI 분석에 최적화된 고품질 프롬프트로 변환해 줍니다.
4.  **안전마진 체크리스트:** 매수 전 필수 점검 항목을 체크하고 현재 준비 상태를 진단할 수 있습니다.
5.  **프롬프트 라이브러리:** 종목 분석, 반대 논리 찾기 등 실전에서 바로 쓸 수 있는 프롬프트를 제공하며 복사 기능을 포함합니다.

## 실행 방법

### 1. 로컬에서 바로 열기
파일 탐색기에서 `index.html` 파일을 더블 클릭하여 브라우저에서 바로 확인할 수 있습니다.

### 2. 로컬 서버로 실행 (권장)
터미널에서 해당 폴더로 이동한 뒤 아래 명령어를 입력하여 로컬 서버를 실행하세요.

**Python 3 사용 시:**
```bash
python3 -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000` 접속

## 기술 스택
*   HTML5
*   CSS3 (Custom Properties, Flexbox, Grid)
*   Vanilla JavaScript (ES6+)

## 주의 사항
*   본 웹앱은 투자 교육 및 학습용으로 제작되었습니다.
*   특정 종목에 대한 매수/매도 추천이 아니며, 모든 투자 판단의 책임은 사용자 본인에게 있습니다.
